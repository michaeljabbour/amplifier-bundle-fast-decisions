## The shape we landed on

1. **Orchestrator-primary composition.** `bundle.md` / `behaviors/fast-decisions.yaml` replace the
   host's `loop-streaming` with `loop-fast-decisions`, which wraps it. Upstream steering, approvals,
   compaction, cancellation and the provider pin keep working. The root's loop config is forwarded.
   Sub-sessions inherit the orchestrator. The dashboard launches from the orchestrator.
2. **One routing decision per turn.** A typed simple/complex question, asked before the first provider
   call, picks model **and** effort for the whole turn, so the prompt cache is never re-written
   mid-turn.
3. **Quality-safe scope gate.** Repository-scale workspaces (more than 300 files) always start on the
   host model. Cheap-first lost quality there.
4. **Pluggable judge.** At measurement time, no judge (length rule) by default; Jev is now the default (see the
   update above). Jev, or a local model, via the
   `overrides.loop-fast-decisions.config` settings override. Local models answer Jev-style typed
   questions.

## Amplifier overhead (the part neither the model nor the judge touches)

- A trivial prompt on this machine's real config (24 app bundles) takes **59 s** and sends a
  **114k-token** prompt. With app bundles disabled: 13 s. The model call is ~2 s either way (one run each;
  `docs/evidence/2026-09-24/followups/install-measurements-2026-09-24.md`).
- **Foundation `hooks-deprecation` walks all of `~/.amplifier`** on every session start, sub-agent
  sessions included: 5.8 s here. The upstream patch in `docs/upstream-patches/` cuts it to 0.002 s
  (72 existing + 6 new tests passing on Python 3.11–3.13 per the PR; the stored independent review checked an earlier
  revision, 72 + 4, in
  `docs/evidence/2026-09-24/followups/reviews/`). A 2026-09-25 profile of the current setup still shows 8.3 s in two
  calls (`docs/evidence/2026-09-25/startup/`).
- On SWE-bench, waiting on the provider is about 80–84% of the turn (median 84% over 165 runs); most of the rest is
  tools. Each run also spends ~12 s on startup and exit (median 12.5 s).

## Follow-ups (same day, after the study)

Records: `docs/evidence/2026-09-24/followups/followups.json`. Small samples; not part of the preregistered protocol.

- **Default model matters.** The study's host was `claude-fable-5-1`. Against `claude-opus-5-5` (list price
  1.3x Sonnet 5 for input/output, 0.7x for cached reads) Sonnet 5 generated about 1.3x faster (113 vs 88 tokens/s,
  4 calls each). The head-to-head was since measured (update at the top): no effect on the Opus holdout.
  `afast savings` prices against the recorded host model and reports negative savings.
- **Four add-ons optimized and merged** (memory #9, behavioral-plasticity #2, design-loop #3, preceptor #7), each
  after an independent Amplifier review (PR records, quoted numbers and reviews in
  `docs/evidence/2026-09-24/followups/extras.json` and `reviews/`). Trivial prompt: 17.5 s without them, 18.5 s with them (2 runs each).
- **One install covers every surface.** `amplifier bundle add --app ...behaviors/fast-decisions.yaml`; the CLI,
  the TUI and Studio (amplifier-runtime) read the same settings. Verified end to end, one prompt each: Jev routed an easy
  turn to Sonnet in the CLI, `amplifier-runtime serve` and the TUI (core 1.6.0) (`docs/evidence/2026-09-25/surface-checks.json`).
  In live sessions the provider-reported cost of every call recorded as Sonnet matched Sonnet 5 pricing (18 of 18),
  and every host call matched Opus 5.5 pricing (356 of 356) (`docs/evidence/2026-09-25/routing-cost-check.json`). An in-session model pick now wins
  (`user_model_strong`); a model set before the session starts is still routable.
- **Defaults changed:** Jev is the default judge (length rule fallback). New: `afast rubric`, `afast savings`,
  dashboard savings panel.
- **Upstream:** the hooks-deprecation fix is open as an optional suggestion,
  https://github.com/microsoft/amplifier-foundation/pull/413.

## Bugs found and fixed along the way (eval infrastructure)

- Receipts were silently dropped: the shared events dir exceeded the 100k-record window. Fixed with
  per-run events dirs.
- The report pipeline crashed on series labels containing `=`, and read `evaluate`'s stdout summary
  instead of `comparison.json`.
- Mechanism gates misread a routing-only config as "backend refused".
- The SWE-bench DTU scaffold never substituted `${SWE_REPO_*}`. A new Forge runner uses official
  swebench 4.x grading and the instance image as the agent's environment.
- Forge `run_command` returns after ~60 s. Completion is now signalled by `result.json`.
- A stale `.git/index.lock` produced empty patches. Patches are now captured through a private index.
- `file://` module activation installs `amplifier_fast_decisions` editable into the shared tool env.
  Runs now pin `PYTHONPATH` to the frozen source.
- Local judges refused every typed question. They now answer choice and yes/no ("noul") questions.
