AI coding agents make many small decisions: which model runs a session, whether a file may be read, whether an action is safe. A system-1 decision model answers such typed questions in a fraction of a second. We measured where these models fit in an agent harness, using judge benchmarks, paired multi-turn sessions on two host models, Fable and Opus (one study preregistered on 60 fresh scenarios) and 19 days of production telemetry. Jev is a hosted typed-decision service. We report five findings. (1) Jev is the cheapest accurate decision model we tested: 55/63 correct at $18.41 per million decisions [preregistered; challenger post hoc]. (2) Route to a cheaper model only when the host is much dearer once caching is counted: 0.581x the plain host on Fable (shipped configuration about 0.75x, replayed), 1.255x on Opus [preregistered, replicated]. (3) Configure model and effort once per session: deciding once about 9-13% cheaper than per turn (descriptive; Fable 95% interval 2-22%) [preregistered criterion; cache expiry exploratory]. (4) Guard risky actions with a deterministic rule: 38 side-effect errors to 0 [preregistered; editable criteria not measured]. (5) Use telemetry for latency and usage, not accuracy: decisions 30x faster than host calls; 34% of judged sessions routed in production [exploratory, one owner]. A fast decision model therefore belongs where a cheap typed judgement changes an expensive or risky action and no simple rule does as well. Session results use one provider's models, scripted tasks and list prices.
